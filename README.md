# AI-ML-internship-tasks

## Day 1: student Management System
Console-based menu-driven app built with Python.

**Run:** `python day1-student-Management-System/student Management System.py`

**Features:** Add, View, Search, Update, Delete, Grade Report
**Bonus:** ID and marks validation, auto grades, average marks, top performer

## Day 2: Mathematics for Machine Learning
Student exam score analysis using Python and Matplotlib.

**Run:** `python day2-math-for-ml/student_score_analysis.py`
**Requires:** `pip install matplotlib`

**Features:** Mean, median, variance, min/max, pass/fail percentage,
probability analysis, bar/line/histogram/scatter graphs

## Day 3: NumPy Basics
Student dataset management using NumPy arrays.

**Run:** `python Day3-NumPy-Basics/student_dataset.py`
**Requires:** `pip install numpy`

**Features:** 20-student dataset (ID, age, 4 subject marks), shape/ndim/size/dtype,
Python list vs NumPy comparison, subject averages, 3D array for two classrooms
